# Repository Explorer & Web Code Editor Guide

SENTRIX.ai includes an integrated In-Browser Code Inspector and Web-to-PR deployer.

## How It Works

1. **Folder & File Navigation:**
   - Enter any repository URL and click **Inspect**.
   - Browse nested directories and files grouped by folders.
   - Filter files in real time using the quick search input.

2. **Code Inspection & Editing:**
   - Select any file to inspect its source code, line counts, and byte sizes.
   - Edit the code directly inside the dark-themed web editor.

3. **Deployment Options:**
   - **Commit & PR:** Direct 1-click branch creation, commit, and GitHub Pull Request / Fork.
   - **Save:** Persist changes to the local workspace.
   - **AI Edit:** Auto-fill task prompt to direct Agno autonomous agents to modify the file.
