# Changelog

All notable changes to the SENTRIX.ai platform are documented in this file.

## [1.2.0] - 2026-11-19

### Added
- Interactive Repository Explorer & in-browser live code editor with folder tree grouping.
- Direct Web-to-PR deployment for immediate GitHub PR creation from the browser.
- External repository GitHub 403 handling with automated fork assistant and direct `.patch` download.
- Full-visibility 24,000-character context window for Agno Developer Agent.
- Non-blocking asynchronous background execution support via daemon threads (`?async=1`).
- Subprocess sandbox hardening with command token filtering and environment isolation.
- Native Voice-to-Task dispatch powered by Web Speech API.
- Inline unified diff editor with automated SHA-256 cryptographic re-hashing.
- Automated GitHub Webhook Bot listening for `@sentrix` issue comments.

## [1.1.0] - 2026-11-18

### Added
- Multi-language AST scanner supporting `.py`, `.js`, `.jsx`, `.ts`, `.tsx`, `.html`, `.css`.
- Multi-file code patch synthesis with automated QA companion tests.
- Human-in-the-loop cryptographic SHA-256 approval gate.
- Split-view side-by-side diff renderer.

## [1.0.0] - 2026-11-17

### Added
- Initial SENTRIX.ai platform architecture (Django Trusted Execution + Agno Multi-Agent Intelligence).
- Planner, Developer, Debugger, and Reviewer multi-agent workflow.
